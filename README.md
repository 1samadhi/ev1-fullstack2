# Tienda Online - Evaluación Parcial 1

## Descripción del Proyecto

Este proyecto es una tienda online básica desarrollada con HTML, CSS (Tailwind) y JavaScript como parte de la Evaluación Parcial 1 del curso Fullstack II.

## Características Implementadas

### Página Principal (HOME)
- ✅ Navegación completa con menú responsive
- ✅ Logo de la tienda y carrito de compras
- ✅ Sección hero con información de la tienda
- ✅ Grid de productos con imagen, nombre y precio
- ✅ Footer con enlaces y formulario de newsletter
- ✅ Diseño responsive para móviles y desktop

## Tecnologías Utilizadas

- **HTML5**: Estructura semántica del sitio
- **Tailwind CSS**: Framework de CSS para estilos
- **Font Awesome**: Iconos
- **JavaScript**: Interactividad básica

## Páginas Desarrolladas

### ✅ Completadas
- **Página Principal (HOME)**: Vista principal con navegación, hero section, productos y footer
- **Inicio de Sesión (LOGIN)**: Formulario de login con validaciones básicas y diseño responsive
- **Registro de Usuario (REGISTER)**: Formulario completo de registro con dropdowns de región/comuna

3. Navegación funcional entre secciones
